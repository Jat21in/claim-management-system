    Claim Management System – Technical Documentation

    Welcome

    Welcome to the official technical documentation for the Claim Management System (CMS) – an enterprise-scale insurance platform built during internship training.

    This documentation suite is designed for:

    Audience Purpose
    Senior Management Understand architectural decisions, technology choices, and system capabilities
    Technical Trainers Evaluate depth of implementation, DDD patterns, and code organisation
    Development Team Onboard quickly, understand data flow, and maintain the system

    Quick Navigation

    Document Description
    System Context External actors, integrations, and system boundaries
    Container Architecture Deployable units: Angular SPA, API, Hangfire, SQL Server
    Domain-Driven Design Aggregates, entities, value objects (Money, Address)
    Application Layer Services, DTOs, and business workflows
    Repository Pattern Data access abstraction with EF Core
    Dependency Injection Service lifetimes and container configuration
    EF Core Configuration Fluent API, migrations, value conversions
    API Controllers Thin controllers, endpoints, authentication
    Middleware & Auth JWT, global exception handling, role-based access
    Angular Structure Standalone components, lazy loading, routing
    Services & Interceptors HTTP interceptors, guards, state management
    Database Schema Complete ERD with 10+ tables
    Migration Strategy EF Core migrations history and commands
    ADR-001: ORM Choice Why EF Core over Dapper
    ADR-002: Thin Controllers Why business logic stays in services
    Glossary Domain-specific terminology

    Key Architectural Decisions

    Decision Rationale ADR Link
    EF Core as ORM LINQ support, migration tooling, value object mapping ADR-001
    Thin Controllers Testability, separation of concerns, reusability ADR-002
    DDD Tactical Patterns Encapsulation of business rules, maintainability Domain Design
    JWT Authentication Stateless, scalable, microservices-ready Middleware & Auth
    Standalone Angular Components Tree-shaking, simpler mental model Angular Structure

    Contributing

    This documentation is maintained alongside the codebase in the doc/ directory. To update:

    1. Edit the relevant .md file
    2. Run mkdocs serve to preview locally
    3. Commit changes to version control

    Build Command:

    mkdocs build --clean

    Deploy Command:

    mkdocs gh-deploy --force
